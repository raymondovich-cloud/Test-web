# Автоматическая публикация тестовой версии LifeGame

- **Дата:** 10.10.2026
- **Время:** 00:25 MSK (UTC+03:00)
- **Пользовательский запрос:** автоматизировать публикацию в среде разработки; основную ветку LifeGame не менять.
- **Изменённые файлы:**
  - `.github/workflows/deploy-pages.yml` — Version 1.0 → 1.1.
- **Изменение:** Test-web принимает событие `lifegame-preview`, сохраняет ручной запуск и резервный запуск по расписанию раз в пять минут. При событии публикации собирается конкретный commit из payload; при запуске по расписанию берётся актуальная `feature/pwa-static-cache`.
- **Кэширование:** во время сборки автоматически добавляется идентификатор commit в URL CSS/JS ресурсов, включая CSS imports; в тестовый `index.html` внедряется метка сборки. Файл `PREVIEW_BUILD.txt` содержит исходный commit и идентификатор сборки.
- **Безопасность и границы:** токен для мгновенного события хранится только в GitHub Secrets репозитория LifeGame. Плановый запуск остаётся резервом, если секрет ещё не настроен. `main` репозитория LifeGame не изменяется; `main` Test-web используется только как управляющая ветка тестовой публикации.
- **Проверка:** после коммита необходимо проверить запуск build/deploy, источник сборки и опубликованный `PREVIEW_BUILD.txt`. Визуальная проверка в Safari остаётся обязательной.
- **Статус:** изменения добавлены; CI и публикация ожидают подтверждения.
